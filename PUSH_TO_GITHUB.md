# 🚀 Push to GitHub - Simple Steps

## Step 1: Open Terminal
Press `Cmd + Space`, type "Terminal", press Enter

## Step 2: Navigate to Your Project
```bash
cd ~/idiotic-betting
```

## Step 3: Push Your Code
```bash
git push -u origin main
```

## Step 4: Enter Credentials
When prompted:
- **Username**: `daksh-rhce`
- **Password**: `PASTE_YOUR_NEW_TOKEN_HERE` (not your GitHub password!)

---

## Alternative: Use Token in URL (One-Time)

If you want to do it in one command:

```bash
git remote set-url origin https://daksh-rhce:YOUR_NEW_TOKEN@github.com/daksh-rhce/idiotic-betting.git
git push -u origin main
```

*(Replace YOUR_NEW_TOKEN with your actual token)*

Your code will be at:
